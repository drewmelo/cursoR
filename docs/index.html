01 - Estatística descritiva e análise exploratória aplicada a dados econômicos

Operações estatísticas

O R possui uma ampla gama de funções estatísticas, tais como média, mediana, variância, desvio padrão, e outros.

library(tidyverse)
# Soma
sum(starwars$height, na.rm = T)
[1] 14143
# Média
mean(starwars$height, na.rm = T)
[1] 174.6049
# Mediana
median(starwars$height, na.rm = T)
[1] 180
# Variância
var(starwars$height, na.rm = T)
[1] 1209.242
# Desvio padrão
sd(starwars$height, na.rm = T)
[1] 34.77416

Operações estatísticas

# Quartis
quantile(starwars$height, na.rm = T)
  0%  25%  50%  75% 100% 
  66  167  180  191  264 
# Produto
prod(starwars$height, na.rm = T)
[1] 5.198489e+180
# Mínimo e máximo
min(starwars$height, na.rm = T)
[1] 66
max(starwars$height, na.rm = T)
[1] 264
# Intervalo 
range(starwars$height, na.rm = T)
[1]  66 264
